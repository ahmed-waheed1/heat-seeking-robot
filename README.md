# Following the Heat to Its Source

Math 3 (BAS 113) project, Badr University in Cairo, Faculty of Engineering & Technology, Basic Science Department, Fall 2026–2027.

A rescue robot at (3, 2) m climbs the temperature field T(x, y) = 100·e^(−(x² + 2y²)/10) °C along the gradient.

- `/`: interactive contour map, the model, the Python code, and the team
- `/explore`: the temperature field as a 3D hill (react-three-fiber)
- `lib/heat.ts`: the math (T, ∇T, directional derivative, gradient path)

```bash
npm install
npm run dev
```
